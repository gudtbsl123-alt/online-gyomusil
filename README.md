# 인천장도초 온라인 교무실

구글 Apps Script 웹앱 + 전용 구글 시트로 만드는 학교 온라인 교무실이에요.
화면 디자인은 `docs/시안/온라인교무실_시안.html`, 범위와 순서는 `docs/구현요청서.md`를 따라요.

## 본인 확인 방식 (2026-10-15 바뀜)
- 기본은 **공통 비밀번호 + 이름 고르기**예요. 개인 번호는 쓰지 않아요.
- 공통 비밀번호와 고른 이름은 기기에 **1년** 기억돼요(관리자 › 설정 '로그인·이름을 기기에 기억하는 기간').
- 교무실 공용 PC에서는 이름을 고를 때 '이 기기에서 기억하기'를 꺼 주세요.
- 개인 번호가 다시 필요하면 관리자 › 설정 › 본인 확인 방식을 '이름+개인 번호'로 바꾸면 돼요.

## 마지막 단계: 최종 코드 넣기와 실제 환경 점검

**[설치안내.md](설치안내.md)를 따라 해 주세요.** 붙여 넣을 파일 12개와 마지막 줄 번호, 처음 설정 다시 하기, 새 버전 배포, 실제 환경 점검 목록, 진짜 시트로 옮기는 순서가 들어 있어요.

## 5단계 · 학사일정 올리기·공지

사진: `docs/스크린샷_5단계/` · 미리보기: `미리보기/미리보기.html`

| 된 것 | 내용 |
| --- | --- |
| 학사일정 한 번에 올리기 | 일정 › '학사일정 올리기'(연구부장·부담당만). 양식(.xlsx) 내려받기 → 엑셀·CSV 파일 고르기 또는 표 붙여 넣기(한글·엑셀) → 미리보기(올릴 수 없음·확인 필요·정상, 줄 고치기·빼기, 올린 뒤 수업일수) → 올리기 → 방금 올린 것 되돌리기 |
| 같은 행사 | 부서가 직접 넣은 행사는 건드리지 않음. 전에 올린 같은 행사는 건너뛰기/새것으로 바꾸기 |
| 공지 | 메뉴 '공지'와 홈 공지 카드. 누구나 쓰기, 쓴 분·관리가 고침, 고정은 관리만, 게시 끝일이 지나면 '지난 공지'로. 검색·휴지통에도 들어감 |

### 5단계 확인 목록 (미리보기·사진)
- [ ] 일정 › 학사일정 올리기에서 양식을 내려받아 행사를 적고 올리면 달력·홈·월별 계획에 보여요
- [ ] 같은 파일을 다시 올리면 '전에 올린 같은 행사'로 나오고, 부서가 넣은 행사는 그대로예요
- [ ] '방금 올린 것 되돌리기'를 누르면 올린 행사가 사라져요
- [ ] 홈 공지 카드에 지금 공지가 보이고, 끝일이 지난 공지는 빠져요
- [ ] (최종 점검 때) 한글에서 복사한 표 붙여 넣기, 양식이 실제 엑셀에서 열리는지 — **확인 필요**

## 4단계 · 자료실·교직원·도움말

웹앱에는 아직 붙여 넣지 않아요. 미리보기(`미리보기/미리보기.html`)와 사진(`docs/스크린샷_4단계/`)으로 확인하고, 마지막 단계를 마친 뒤 최종 코드를 한 번에 넣어요.

| 된 것 | 내용 |
| --- | --- |
| 자료실 | 맨 위 **공통 자료**(비상연락망·출결 양식·가정통신문 양식·표준 기안문 등, 번호로 순서) → 아래 부서별 자료 카드(분류·제목·설명·담당·고친 날), 찾기, 부서·분류로 거르기. 링크 넣기 또는 파일 올리기 |
| 파일 올리기 | 공유하지 않는 드라이브 폴더 '온라인 교무실 자료'에 저장, 온라인 교무실을 거쳐서만 내려받기. 크기 한도는 설정(기본 10MB, 확인 필요) |
| 권한 | 넣기는 이름을 고른 교직원 누구나, 고치기·지우기는 처음 넣은 분과 관리. 홈 '자주 찾는 자료' 표시는 관리만 |
| 보관함·새 학년도 | 관리자 › 새 학년도: 지금 자료를 모두 보관함으로 보내고, 고른 자료만 새 학년도로 옮겨 적기(처음 넣은 분·파일 그대로). 보관함 자료는 관리가 '지금 학년도로 꺼내기' |
| 교직원 명단 | 이름·직위·소속·부서·담당 업무·내선, 찾기·부서로 거르기, 인쇄 |
| 도움말 | 분류(복무·인사, 학교 규칙·제규정 등)별 글, 링크·파일 붙이기, 찾기. 누구나 쓰고 처음 쓴 분·관리가 고침. 내용은 학교에서 넣어요(앱이 규정을 지어내지 않음) |
| 운영 안내서 | 모든 선생님용(들어오기·홈·일정·조사·자료) + 연구부장·부담당용(관리자 화면·학기 초·새 학년도·데이터 지키기), 인쇄 |
| 홈 검색 | 자료·일정·교직원·도움말·조사를 한 번에 찾기(띄어쓰기 무시). 홈 '처음이세요?' 안내, '자주 찾는 자료' |
| 휴지통 | 지운 자료·도움말도 관리자 › 휴지통에서 되살리기 |

### 4단계 확인 목록 (미리보기·사진)
- [ ] 홈 검색창에 '협의'·'정보부'·선생님 이름을 넣으면 자료·일정·교직원이 함께 나와요
- [ ] 관리자 › 새 학년도로 넘기면 지난 자료가 보관함으로 가고, 고른 자료만 새 학년도에 보여요
- [ ] (최종 점검 때, 실제 웹앱) 파일 올리기·내려받기, 한글 파일 이름이 그대로 받아지는지, 올릴 수 있는 최대 크기 — **확인 필요**

| 제출 현황 | 낸 사람·안 낸 사람·응답률, 안 낸 분 명단, 메신저 문구 복사, 안 낸 분께 다시 알리기, 지금 끝내기·다시 열기, 고치기·마감 연장, 지우기 |

| 홈 '내가 할 일' | 아직 안 낸 조사. 다시 알림 받은 것이 맨 위, 메뉴에 숫자 표시 |

### 3단계 확인 목록 (테스트 시트)
- [ ] 시트 메뉴 **테스트용 가짜 조사 넣기** → 조사·신청에 2개가 보여요
- [ ] 다른 이름으로 바꿔 응답하면 만든 분 화면의 '낸 사람' 숫자가 바로 바뀌어요
- [ ] 같은 사람이 다시 내면 새 응답이 아니라 고치기가 돼요(시트 '응답' 탭 줄 수가 늘지 않아요)
- [ ] **안 낸 분께 다시 알리기** → 안 낸 분으로 바꿔 보면 홈 '내가 할 일' 맨 위에 '다시 알림'으로 보여요
- [ ] **문구 복사**가 돼요 (확인 필요: Apps Script 화면에서 복사가 되는지)
- [ ] **엑셀로 받기 › 파일 내려받기**가 돼요 (확인 필요: 안 되면 '표 복사'로 붙여 넣기)

## 2단계 · 일정과 홈

| 된 것 | 내용 |
| --- | --- |
| 행사 넣기·고치기·지우기 | 본인 확인한 분이 넣어요. 고치기·지우기는 처음 넣은 분, 역할 '관리'인 분, 관리자 화면을 연 분만. 지운 일정은 관리자 › 휴지통에서 되살려요 |
| 구분 | 행사 / 교육활동 / 휴업일 / 공휴일. 휴업일·공휴일은 수업일수에 영향을 줘서 연구부장·부담당만 넣어요 |
| 대상 | 1~6학년 여러 개 + 전체 + 교직원 |
| 일정 › 달력 | 월 달력(PC), 이번 주 보기(휴대폰), 학년·부서·내 담당(내 부서 + 내가 넣은 것) 필터, 이달 수업일수, 이달 중점지도 |
| 일정 › 월별 계획 | 날짜·요일·행사·교육활동·담당 부서 표. 인쇄하면 흰 바탕 |
| 일정 › 연간 학사일정 | 3월~이듬해 2월, 학기별·연간 수업일수와 계산 방법, 빠진 날 목록 |
| 홈 | 오늘 일정, 내일 미리 보기, 이번 주 일정(전체·우리 학년·내 담당), 이달 중점지도 + 학생 수 현황(학년별·전체, 학년을 누르면 반별 남·여, 교직원 누구나 고침), 기존 시트 바로가기 |
| 수업일수 계산 | 학기 기간(설정)의 평일 − 휴업일·공휴일이 걸린 평일(겹치면 한 번). 학기 기간이 없으면 계산하지 않고 비워 둬요 |

### 2단계 확인 목록 (테스트 시트)
- [ ] 관리자 화면 › 설정에 1·2학기 시작일·끝일을 넣어요 (확인 필요: 학교 학사일정 값)
- [ ] 시트 메뉴 **테스트용 가짜 일정 넣기**를 누르면 홈에 오늘·이번 주 일정이 보여요
- [ ] 일정 › 달력에서 **행사 추가** → 저장하면 달력·월별 계획·연간 학사일정·홈에 함께 보여요
- [ ] 다른 선생님(역할 '일반')으로 본인 확인하면 남이 넣은 행사는 고치기 단추가 없어요
- [ ] 행사를 지우면 관리자 › 휴지통에 보이고, 되살리면 다시 나타나요
- [ ] 연간 학사일정의 학기별 수업일수가 기존 학사일정 표의 값과 같아요 (기획문서 기준 2026학년도 1학기 95일·2학기 95일, 연 190일 — 공휴일·휴업일을 모두 넣은 뒤 비교)
- [ ] 월별 계획 › **인쇄**가 흰 바탕으로 나와요 (확인 필요: Apps Script 화면에서 인쇄 창이 열리는지)
- [ ] 휴대폰에서 일정 › 이번 주 보기와 **한 달 보기**가 옆으로 넘치지 않아요

일정·조사·자료실·교직원 명단·도움말 메뉴는 '○단계' 표시와 함께 자리만 있어요.

## 비밀번호·개인 번호는 어디에 있나요?

- 공통·관리자 비밀번호: 스크립트 속성에 **해시로만** 저장돼요. 원래 글자는 코드·시트·화면·기록 어디에도 없어요.
- 개인 번호 4자리: 교직원 탭에 사람마다 다른 솔트와 비밀 값(스크립트 속성 `PIN_PEPPER`)을 섞은 해시로만 저장돼요.
- 브라우저에는 서명한 로그인 표만 남고, 번호·비밀번호 자체는 남지 않아요.

## 선생님이 직접 하실 일 (테스트용 시트로 먼저)

### 1. 테스트용 시트 만들기
1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 누르세요.
2. 왼쪽 위 이름을 `온라인 교무실 (테스트)`로 바꾸세요.

### 2. Apps Script에 코드 넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누르세요. 새 탭이 열려요.
2. 왼쪽 위 프로젝트 이름(제목 없는 프로젝트)을 눌러 `온라인 교무실`로 바꾸세요.
3. 왼쪽 **파일** 목록의 `Code.gs`를 누르고, 안의 내용을 모두 지운 뒤 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣으세요.
4. **파일 옆 + → 스크립트**를 눌러 아래 8개를 만들고, 같은 이름의 파일 내용을 붙여 넣으세요. 이름에 `.gs`는 자동으로 붙어요.
   - `Db`, `Auth`, `Admin`, `Schedule`, `Survey`, `Library`, `Help`, `Setup`

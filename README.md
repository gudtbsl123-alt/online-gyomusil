# 인천장도초 온라인 교무실

구글 Apps Script 웹앱 + 전용 구글 시트로 만드는 학교 온라인 교무실이에요.
화면 디자인은 `docs/시안/온라인교무실_시안.html`, 범위와 순서는 `docs/구현요청서.md`를 따라요.

## 지금 단계: 1단계 · 뼈대와 로그인

| 된 것 | 내용 |
| --- | --- |
| 시트 자동 설정 | 메뉴 한 번으로 탭 11개(설정·분류·교직원·일정·월별중점·조사·응답·알림·자료·도움말·기록)와 머리글을 만들어요. 여러 번 눌러도 있는 데이터는 그대로예요 |
| 공통 로그인 | 공통 비밀번호로 들어와요 |
| 본인 확인 | 명단에서 이름 고르기 + 개인 번호 4자리. 5번 틀리면 10분 잠김. '이 기기에서 기억하기'는 30일 |
| 관리자 화면 | 관리자 비밀번호(공통과 다름)로 들어가요. 2시간 동안 열려 있어요 |
| 교직원 표 | 추가·고치기·사용 안 함/다시 사용·개인 번호 만들기(한 번만 보여 줌, 쪽지 인쇄)·잠금 풀기 |
| 분류 | 부서·자료 분류·도움말 분류. 이름을 한 곳에서 바꾸면 모든 화면에 함께 바뀌어요 |
| 설정 | 학교명·학년도·학기 기간·잠금 기준·기억 기간·백업 개수·기존 시트 바로가기 |
| 데이터 보호 3겹 | ① 지우지 않고 숨김 표시(되살리기 가능) ② 고칠 때마다 '기록' 탭에 누가·언제·바뀌기 전·바뀐 뒤 ③ 매일 새벽 시트 전체 백업(30개 보관) |
| 화면 기본 | PC 사이드 메뉴, 휴대폰 하단 메뉴, 밝게·어둡게, 글자 크게, 인쇄하면 흰 바탕 |

일정·조사·자료실·교직원 명단·도움말 메뉴는 '○단계' 표시와 함께 자리만 있어요.

## 비밀번호·개인 번호는 어디에 있나요?

- 공통·관리자 비밀번호: 스크립트 속성에 **해시로만** 저장돼요. 원래 글자는 코드·시트·화면·기록 어디에도 없어요.
- 개인 번호 4자리: 교직원 탭에 사람마다 다른 솔트와 비밀 값(스크립트 속성 `PIN_PEPPER`)을 섞은 해시로만 저장돼요.
- 브라우저에는 서명한 로그인 표만 남고, 번호·비밀번호 자체는 남지 않아요.

## 선생님이 직접 하실 일 (테스트용 시트로 먼저)

### 1. 테스트용 시트 만들기
1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 누르세요.
2. 왼쪽 위 이름을 `온라인 교무실 (테스트)`로 바꾸세요.

### 2. Apps Script에 코드 넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누르세요. 새 탭이 열려요.
2. 왼쪽 위 프로젝트 이름(제목 없는 프로젝트)을 눌러 `온라인 교무실`로 바꾸세요.
3. 왼쪽 **파일** 목록의 `Code.gs`를 누르고, 안의 내용을 모두 지운 뒤 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣으세요.
4. **파일 옆 + → 스크립트**를 눌러 아래 4개를 만들고, 같은 이름의 파일 내용을 붙여 넣으세요. 이름에 `.gs`는 자동으로 붙어요.
   - `Db`, `Auth`, `Admin`, `Setup`
5. **파일 옆 + → HTML**을 눌러 아래 3개를 만들고, 같은 이름의 파일 내용을 붙여 넣으세요. 이름에 `.html`은 자동으로 붙어요.
   - `Index`, `Styles`, `App`
6. 왼쪽 **톱니바퀴(프로젝트 설정)**를 눌러 **시간대**를 `(GMT+09:00) 서울`로 바꾸세요.
7. 위의 **저장(디스크 그림)**을 누르세요.

### 3. 처음 설정과 비밀번호
1. 시트 탭으로 돌아가 **새로 고침**을 누르세요. 몇 초 뒤 메뉴에 **온라인 교무실**이 생겨요.
2. **온라인 교무실 → 1. 처음 설정 (탭 만들기)**를 누르세요.
3. 처음 한 번은 권한을 물어요. 아래 순서로 허용해 주세요.
   - **계속** → 내 구글 계정 고르기
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 온라인 교무실(으)로 이동(안전하지 않음)**을 누르세요. 직접 만든 스크립트라서 나오는 안내예요.
   - **허용**을 누르세요(시트 읽기·쓰기, 드라이브 백업 폴더 만들기에 필요해요).
4. 다시 **1. 처음 설정**을 누르면 "처음 설정을 마쳤어요"가 떠요.
5. **2. 공통 비밀번호 정하기** → 6자 이상 두 번 넣기 → **정하기**
6. **3. 관리자 비밀번호 정하기** → 공통과 다른 6자 이상 → **정하기**
7. (테스트 시트에서만) **테스트용 가짜 데이터 넣기** → **예**. 가짜 교직원 8명(홍길동 등)과 개인 번호 표가 나와요. 번호를 적어 두세요.
8. (선택) **4. 매일 자동 백업 켜기** → 내 드라이브에 '온라인 교무실 백업' 폴더가 생기고 첫 백업이 만들어져요.

### 4. 웹앱으로 배포하기
1. Apps Script 탭 오른쪽 위 **배포 → 새 배포**를 누르세요.
2. **유형 선택(톱니바퀴) → 웹 앱**을 고르세요.
3. 설명: `1단계 테스트`
4. **다음 사용자 인증 정보로 실행: 나**
5. **액세스 권한이 있는 사용자**: 테스트 동안은 **나만**을 고르세요. (진짜 배포 때는 '학교 도메인 사용자만' 또는 '모든 사용자' 중에서 골라요 — 확인 필요)
6. **배포**를 누르고, 나오는 **웹 앱 URL**을 복사해 새 탭에서 여세요.

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누르면 주소가 그대로 유지돼요.

### 5. 1단계 확인 목록
- [ ] 웹 앱 주소를 열면 '어서 오세요'와 공통 비밀번호 칸이 보여요
- [ ] 틀린 비밀번호는 거절되고, 맞는 비밀번호로 '누구신가요?'로 넘어가요
- [ ] 이름을 고르고 개인 번호를 넣으면 홈과 '본인 확인됨'이 보여요
- [ ] 번호를 5번 틀리면 10분 잠겨요(관리자 화면 '잠금 풀기'로 바로 풀 수 있어요)
- [ ] 관리자 → 관리자 비밀번호 → 교직원 추가·고치기·번호 만들기·사용 안 함이 돼요
- [ ] 분류에서 부서 이름을 바꾸면 교직원 표의 부서 이름도 바뀌어요
- [ ] 시트의 '기록' 탭에 누가·언제·바뀌기 전·바뀐 뒤가 남아요
- [ ] 시트 어디에도 비밀번호·개인 번호 원래 숫자가 없어요
- [ ] 휴대폰으로 열어도 화면이 옆으로 넘치지 않아요
- [ ] 휴대폰에서 '이 기기에서 기억하기'를 켜고, 창을 닫았다 다시 열어도 로그인돼 있어요 (확인 필요: Apps Script 화면에서 브라우저 저장이 되는지)

## 개발용 (선생님은 안 보셔도 돼요)

```bash
node tools/test.js            # 서버 코드 자동 시험 (가짜 시트)
node tools/build-preview.js   # 미리보기/미리보기.html 만들기
node tools/shots.js           # 미리보기를 브라우저로 눌러 보며 사진 찍기 → docs/스크린샷
```

- `미리보기/미리보기.html`을 브라우저로 열면 서버 없이 가짜 데이터로 화면을 볼 수 있어요. (공통 `preview1` · 관리자 `admin1` · 개인 번호 `1111`)
- `tools/`의 파일은 웹앱에 올리지 않아요.

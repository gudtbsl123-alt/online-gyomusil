# 온라인 교무실 구현 요청서 (Claude Code용)

작성 2026-10-15 · 인천장도초등학교 온라인 교무실 1차 구축

이 문서는 Claude Code에게 '무엇을, 어떤 규칙으로, 어떤 순서로' 만들지 알려 주는 요청서예요. 함께 넣는 파일은 두 개예요.

| 파일 | 역할 |
| --- | --- |
| `온라인교무실_시안.html` | 화면 디자인의 기준. 브라우저로 열면 화면 8장을 눌러 볼 수 있음 |
| `기획문서.md` | 기존 협의회 시트 분석, 필요 기능 49개, 확정 사항, 보안 원칙, 출시 준비 |

**표시 규칙**: **(확정)**은 선생님이 이미 정한 것, **(보완안)**은 기획 문서에 보완안으로 적고 적용하기로 한 것, **(제안)**은 구현하기 좋게 이 요청서에서 정리한 안(계획 단계에서 확인받기), **(확인 필요)**는 아직 정해지지 않아 선생님께 물어봐야 하는 것이에요.

---

## 0. Claude Code 작업 규칙

1. **계획 먼저.** 코드를 쓰기 전에 무엇을 어떻게 만들지 계획을 보여 주고, 선생님의 확인을 받은 뒤 시작해요.
2. **단계별로.** 7장의 순서대로 한 단계씩 만들고, 단계가 끝날 때마다 멈추고 확인을 받아요.
3. **원본을 덮어쓰지 않기.** 넣어 준 파일(시안·문서)은 고치지 않아요. 바꿔야 하면 사본을 만들어요. 파일을 지울 때는 먼저 물어봐요.
4. **추측하지 않기.** 확실하지 않은 숫자·사실·설정은 지어내지 말고 '확인 필요'로 표시하고 물어봐요.
5. **개인정보를 넣지 않기.** 코드·예시 데이터·테스트에 실제 교직원·학생 이름, 연락처, 계정, 비밀번호를 쓰지 않아요. 예시 이름은 '홍길동'처럼 가짜만 써요.
6. **말은 쉽게.** 선생님께 설명할 때는 전문 용어를 줄이고, 선생님이 직접 해야 하는 일은 클릭 순서대로 안내해요.

## 1. 만들 것 한 줄 요약

**구글 Apps Script 웹앱 + 전용 구글 시트**로 만드는 학교 '온라인 교무실'이에요 **(확정)**. 교직원이 일정·조사·자료를 한 번만 입력하면 여러 화면에 함께 보이게 하는 것이 핵심이에요. 화면 모양은 `온라인교무실_시안.html`을 따라요.

- 사용자: 인천장도초 교직원. 2026학년도 참석 명단 문서의 집계 칸 기준 56명
- 관리: 연구부장 1명 + 부담당 1명
- 기기: 학교 PC 브라우저와 개인 휴대폰

## 2. 확정 사항 (바꾸지 말 것)

| 항목 | 내용 |
| --- | --- |
| 구조 | Apps Script 웹앱(HtmlService)이 화면을 보여 주고, 데이터는 **새로 만든 전용 구글 시트**에 저장 **(확정)** |
| 원본 시트 | 기존 협의회 시트는 다른 선생님 소유. 웹앱이 **읽지도 쓰지도 않음**. 필요한 내용은 소유 선생님 동의를 받은 뒤 사람이 옮김 **(확정)** |

| 뺀 것 | 봉봉클래스식 학급 배정·전담시간표 작성 기능은 만들지 않음 **(확정)** |
| 2차로 미룬 것 | 특별실 시간표, 방학 근무 배정, 법정연수 이수 확인. 1차에는 홈의 '아직 기존 시트에서 하는 일' 바로가기만 둠 **(확정)** |
| 화면 기본 | 밝은 화면이 기본이고 '밝게·어둡게' 전환. 인쇄하면 흰 바탕·검은 글씨, 메뉴·버튼은 숨김 **(확정)** |

## 4. 디자인 기준

### 시안 HTML 쓰는 법

- 화면마다 `<section class="screen" id="Main">`처럼 나뉘어 있고, 주소 끝의 `#Main` 같은 표시로 화면을 바꿔요. Apps Script도 페이지 하나에 화면을 나눠 담는 방식이 잘 맞아요 **(제안)**.
- 색은 CSS 변수(`--c-bg`, `--accent` 등)로 되어 있고 `<html data-theme="light|dark">`로 밝기가 바뀌어요. **이 변수 이름과 값을 그대로 가져다 쓰세요.**
- 시안 속 이름·날짜·숫자는 모두 예시예요. 실제 화면은 시트 데이터로 채워야 해요.
- 인쇄 규칙(`.print-root`, `.print-hide`, `.print-keep`)과 입력칸 안내 글자 규칙(`currentColor`, 투명도 0.7)도 그대로 써요.

### 모양 원칙

- 글꼴: Pretendard. jsDelivr의 `pretendard@1.3.9` dynamic-subset CSS로 불러오고, 안 되면 기기 기본 글꼴(Apple SD Gothic Neo, Malgun Gothic)로 보여요.
- 글자 크기: 본문 16~17px, 보조 13~15px, PC 제목 32px, 휴대폰 제목 22~23px.
- 누르는 곳은 최소 44px. 모서리 둥글기 12·14·16·20px.
- 글자 대비는 WCAG AA(4.5:1) 이상. 시안의 토큰 조합은 확인을 마쳤어요.
- 말투: 해요체, 짧고 쉬운 말. 예: "누르면 그분들 홈 화면의 '내가 할 일' 맨 위에 다시 보여요."
- 새로 설계하는 화면(로그인, 자료실, 교직원, 도움말, 관리자, 새 조사 만들기, 운영 안내서)도 같은 토큰과 컴포넌트로 만들어요.

## 5. 데이터 구조 — 전용 시트 탭 (제안, 확인 후 확정)

시트 탭 하나가 표 하나예요. 1행은 머리글이에요. ID는 앱이 만들어요. **비밀번호는 어느 탭에도 넣지 않아요**(6장).

| 탭 | 열 | 메모 |
| --- | --- | --- |
| `설정` | 키, 값 | 학년도, 학교명, 1·2학기 시작일·끝일, 기존 시트 바로가기 이름·링크, 메뉴 표시 여부 |
| `교직원` | 교직원ID, 이름, 직위, 소속(학년·반 또는 교과), 부서, 담당 업무, 내선, 역할(일반/관리), 사용 여부(사용/사용 안 함), 개인번호해시, 솔트, 틀린 횟수, 잠금 해제 시각, 번호 바꾼 날 | 개인 연락처는 넣지 않음. 전출·휴직하면 '사용 안 함' |
| `일정` | 일정ID, 시작일, 끝일, 시간(또는 교시), 행사명, 대상 학년, 담당 부서, 장소, 구분(행사/휴업일/공휴일), 메모, 입력자ID, 입력 시각, 수정자ID, 수정 시각, 올린 묶음ID, 삭제 여부 | 학사일정·월별 계획·홈이 모두 이 탭 하나를 읽음 |
| `월별중점` | 학년도, 월, 중점지도 내용 | 일정 화면의 '10월 중점지도' 카드 |
| `조사` | 조사ID, 제목, 부서, 만든이ID, 대상, 마감 일시, 상태(진행 중/끝남), 질문(JSON), 메신저 문구, 만든 시각 | 질문 형식: 하나 고르기, 여러 개 고르기, 짧은 글 **(제안)** |
| `응답` | 응답ID, 조사ID, 교직원ID, 답(JSON), 하고 싶은 말, 낸 시각, 고친 시각 | 마감 전에는 고칠 수 있음 |
| `알림` | 조사ID, 대상 교직원ID, 알린 시각 | '안 낸 분께 다시 알리기' 기록. 홈 '내가 할 일' 맨 위에 올림 |
| `자료` | 자료ID, 학년도, 부서, 제목, 설명, 링크, 담당, 수정일, 보관 여부 | 새 학년도에 복제 |
| `도움말` | 항목ID, 분류(복무·인사/규칙·제규정), 제목, 내용, 링크, 수정일 | |
| `기록` | 시각, 교직원ID, 대상(탭·ID), 동작(추가/수정/삭제), 요약 | 수정 이력. 학년도가 끝나면 보관 |

- **수업일수 계산 (제안)**: 학기 기간(설정) 안의 평일에서 `일정`의 '휴업일·공휴일'을 뺀 날 수. 2026.학사일정에 적힌 값(1학기 95일·2학기 95일, 연 190일)과 같게 나오는지로 검산해요.
- **월별 계획 (제안)**: 따로 입력하지 않고 `일정`을 월별로 모아 보여 주고, 지금 양식처럼 인쇄해요.

## 6. 보안·개인정보 규칙 (꼭 지킬 것)

1. **공통 비밀번호와 관리자 비밀번호**는 Apps Script의 스크립트 속성(Script Properties)에만 둬요. 코드·시트·화면·로그에 적지 않아요. 학기 초에 바꿀 수 있게 해요.
2. **개인 번호 4자리**는 원래 숫자를 저장하지 않아요. 사람마다 다른 솔트를 붙여 해시(SHA-256, `Utilities.computeDigest`)로 저장하고, 비교도 해시로 해요 **(제안)**. 4자리는 경우의 수가 적어서, 시트를 볼 수 있는 사람이 해시를 하나씩 맞춰 볼 수 없도록 스크립트 속성에 둔 비밀 값(pepper)도 함께 섞어요 **(제안)**.
3. **여러 번 틀리면 잠시 잠금** **(보완안)**. 몇 번 틀리면 몇 분 잠글지는 확인 필요예요(예: 5번에 10분).
4. **번호를 잊으면** 연구부장·부담당이 관리자 화면에서 다시 정해 줘요 **(보완안)**. 처음에 번호를 나눠 주는 방법은 확인 필요예요.
5. **기기 기억하기**는 만료 기한이 있는 표시만 브라우저에 저장하고, 번호 자체는 저장하지 않아요. Apps Script 웹앱 화면에서 브라우저 저장이 잘 되는지는 직접 확인해야 해요 **(확인 필요)**.
6. **학생 정보**(이름·계정·배경)는 올리지 않아요. 교무실에는 '어디서 받는지'만 안내해요.
7. **교직원 개인 연락처**는 넣지 않아요(내선만). 비상연락망은 1차에 넣지 않아요.
8. **전용 시트 공유**: '링크가 있는 모든 사용자' 공개는 쓰지 않아요. 시트 편집 권한은 관리자(연구부장·부담당)에게만 주고, 교직원은 웹앱으로만 들어와요 **(제안)**.
9. **동시에 저장해도 안 꼬이게** 시트에 쓸 때는 잠금(`LockService`)을 써요 **(제안)**.
10. **기록**: 추가·수정·삭제는 `기록` 탭에 남겨요(공통 계정 동안은 본인 확인한 이름으로).

## 7. 단계별 구현 순서와 완료 기준

각 단계가 끝나면 멈추고, 선생님이 테스트용 시트에서 확인한 뒤 다음 단계로 넘어가요.

### 1단계 · 뼈대와 로그인
- 시트 탭·머리글을 자동으로 만드는 설정 함수
- 공통 비밀번호 로그인 → 이름 고르기 + 개인 번호 → 본인 확인됨 표시
- 관리자 비밀번호로 관리자 화면 들어가기, 교직원 표 관리(추가·수정·사용 안 함·번호 다시 정하기)
- 공통 화면 틀: PC 사이드 메뉴, 휴대폰 하단 메뉴, 밝게·어둡게, 인쇄 모양
- **완료 기준**: 테스트 시트에서 로그인부터 본인 확인까지 됨 / 비밀번호가 코드·시트에 없음 / 틀린 번호를 반복하면 잠김 / 휴대폰 폭에서 화면이 옆으로 넘치지 않음

### 2단계 · 일정과 홈
- 행사 추가·수정·삭제(입력자 기록), 월 달력, 이번 주 보기, 학년·부서·내 담당 필터
- 연간 학사일정 보기, 수업일수 자동 계산, 월별 계획 보기·인쇄
- 홈: 오늘 일정, 이번 주 일정, 내일 미리보기, '아직 기존 시트에서 하는 일' 바로가기
- **완료 기준**: 한 번 입력한 행사가 달력·월별 계획·홈에 함께 보임 / 수업일수 검산 방법이 화면에 나옴 / 월별 계획 인쇄가 흰 바탕으로 나옴

### 3단계 · 조사·신청
- 새 조사 만들기(질문, 대상, 마감), 응답 화면(이름 + 개인 번호), 마감 전 고치기
- 내가 만든 조사: 낸 사람·안 낸 사람·응답률, 안 낸 분 목록, 다시 알리기, 메신저 문구 복사, 응답 내려받기(범위는 3장 표대로 확인)
- 홈 '내가 할 일'(3장 표대로 확인)
- **완료 기준**: 응답하면 제출 현황 숫자가 바로 바뀜 / 다시 알리면 그 사람 홈 맨 위에 보임 / 같은 사람이 두 번 내면 새 응답이 아니라 고치기가 됨

### 4단계 · 자료실·교직원·도움말
- 자료 카드, 검색, 학년도 보관과 새 학년도 복제
- 교직원 명단(직위·소속·담당 업무·내선)
- 도움말(복무·인사 안내, 학교 규칙·제규정), 운영 안내서 화면
- **완료 기준**: 홈 검색창에서 자료·일정·교직원을 찾을 수 있음 / 새 학년도 복제 뒤 지난 자료가 보관함으로 감

### 5단계 · 선택 기능 (선생님이 넣기로 정한 것만)
- 학사일정 엑셀로 올리기: 목록 양식 내려받기 → 파일 고르기 → 미리보기(확인 필요한 줄 표시) → 겹치면 건너뛰기/바꾸기 → 올리기 → '방금 올린 것 되돌리기'. 부서가 직접 넣은 행사는 지우지 않음
- 공지, 응답 요약 그래프 등 3장 표에서 넣기로 정한 것

## 8. 테스트와 배포

- **테스트는 사본으로**: 테스트용 시트를 따로 만들어 가짜 데이터로 확인한 뒤, 진짜 전용 시트에 배포해요.
- **화면 미리보기**: 서버 호출(`google.script.run`)을 가짜 데이터로 바꿔 끼울 수 있게 해 두면, 배포 전에 브라우저에서 화면을 확인할 수 있어요 **(제안)**.
- **확인할 기기**: 학교 PC 브라우저(크롬·웨일·엣지)와 휴대폰.
- **선생님이 직접 할 일**: Claude Code는 아래 일을 클릭 순서대로 안내해 주세요.
  1. 전용 구글 시트 만들기(어느 계정에 둘지 먼저 정하기)
  2. 시트에서 Apps Script 열고 코드 넣기(또는 `clasp`로 올리기)
  3. 스크립트 속성에 공통 비밀번호·관리자 비밀번호 넣기
  4. 웹앱으로 배포하고 권한 승인하기(실행 계정과 접근 범위 정하기)
  5. 웹앱 주소를 교직원에게 알리기
